## Fitur Aplikasi

1. **Login Page**
   - Login menggunakan email dan password.
   - Validasi input menggunakan Form dan Validator.
   - Navigasi ke halaman profil setelah login berhasil.

2. **Profile Page**
   - Menampilkan foto profil mahasiswa.
   - Menampilkan nama, NIM, program studi, kelas, dan bio.
   - Menampilkan informasi kontak berupa email, nomor telepon, dan GitHub.

3. **Edit Profile Page**
   - Mengubah nama, email, dan nomor telepon.
   - Menggunakan TextEditingController.
   - Validasi data sebelum disimpan.
   - Memperbarui informasi profil setelah data berhasil disimpan.

4. **About Me Page**
   - Menampilkan informasi tentang diri sendiri.
   - Menampilkan keterampilan dan hobi.
   - Menampilkan riwayat pendidikan.

5. **Theme Mode**
   - Mendukung Light Mode dan Dark Mode.
   - Pengguna dapat mengganti tema aplikasi.

6. **Navigasi Aplikasi**
   - Menggunakan Drawer untuk berpindah halaman.
   - Menggunakan Navigator untuk membuka halaman lain dan mengembalikan data.

## Cara Menjalankan Aplikasi

Pastikan Flutter dan Dart sudah terinstal di komputer.

1. Clone repository:

```bash
git clone https://github.com/nathanedyansyah2-svg/uts-pml-1124160098.git
```

2. Masuk ke folder project:

```bash
cd soal2_profil_app
```

3. Install dependencies:

```bash
flutter pub get
```

4. Jalankan aplikasi:

```bash
flutter run
```
